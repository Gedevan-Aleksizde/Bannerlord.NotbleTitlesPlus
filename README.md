# Noble Titles Plus

_Noble Titles Plus_ is a remake of Zijistark's Noble Titles mod for [Mount & Blade II: Bannerlord](https://www.taleworlds.com/en/Games/Bannerlord). Much more information is available on [Nexus](https://www.nexusmods.com/mountandblade2bannerlord/mods/5348).

This version targets Bannerlord **v1.5.7** and is built against Bannerlord.ReferenceAssemblies **1.5.7.125802**, MCM **5.13.1**, and Harmony **2.4.2**.

Use **Title Display Locations** in MCM to choose where Noble Titles Plus modifies names: **Encyclopedia List**, **Encyclopedia Details**, **Conversation Screen**, **Settlement Character List**, **Party Tooltips**, **Links in Text**, and **Other Screens**. Disable an option to use the game's original display. All seven options are enabled by default and saved per campaign.
